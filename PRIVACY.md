# Privacy Policy — Ship Context

Ship Context reads Jira issue data (summaries, statuses, priorities, links,
estimates and assignee display names) inside the Atlassian site where it is
installed, solely to compute the release-readiness analysis shown to the
requesting user.

- No personal data is copied, exported or stored outside Atlassian's Forge
  runtime. The app stores no user data in its own key-value store except
  per-connection connector configuration (repository owner/name).
- The optional GitHub connector fetches public repository metadata and pull
  request titles/branch names and ingests them into Atlassian's Teamwork Graph,
  where Atlassian's own data policies apply.
- No analytics, tracking, or third-party data sharing.
